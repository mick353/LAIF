# LAIF public presentation

## Positioning

LAIF helps governance, assurance and procurement reviewers turn AI policy promises into controls they can inspect. Lead with the decision and deliverables, show actual output, then offer a small runnable example. Keep framework theory and repository history available through progressive disclosure.

Primary audiences: AI governance and assurance teams; procurement reviewers; test and release managers. Supporting audiences: policy teams and researchers.

The front page leads to three concrete actions: run the synthetic example, inspect its generated assessment, or read the executive brief. It does not imply a hosted application or customer deployment.

## Visual system

- Deep navy and warm off-white: a professional document-review context.
- Teal: source traceability and constructive control design.
- Restrained amber: questions and review points, rather than alarm or a certification seal.
- Clean vector illustrations, readable type and generous spacing.
- No client logos, invented testimonials, accreditation badges, AI-brain imagery or unsupported performance claims.

Assets in `docs/assets/` are self-contained SVGs with text alternatives in the README. The social-preview PNG is rendered from its SVG source. `laif-social-preview.png` is a 1280×640 repository sharing image; uploading it to GitHub's Social preview setting is a separate operation from committing it.

## Claim and adoption discipline

- “Local toolkit”, “standard-library core” and “no model API key” describe the implemented text/Markdown path.
- Word/PDF extraction is optional and depends on installed parsers.
- Published tests demonstrate software behaviour, not universal detection accuracy or production effectiveness.
- Generated example output is actual output from synthetic input; it is not a customer success story.
- Preserve the distinction between external diagnostic assessment and strict LAIF-native certification.
- Do not call the repository open source or promise commercial reuse until the owner selects a distribution licence. No licence has been added as part of this presentation change.
- No advertising accounts, analytics, domain, paid service, mailing list or public outreach is established by this work.
