## What changed

Any local source can now carry a substantive authored LAIF assessment, with all
eight criterion records, explicit Q1a/Q1b, applicability, framework basis,
qualifications, alternative explanations, closing evidence and curated exact
source spans. The executive finding leads with the author's actual reasoning.
These are attributed judgements, not conclusions generated by keyword matching.

The optional all-criterion gate rejects incomplete coverage before output writes.
Partial reviews remain valid without the gate and omitted areas stay unassessed.
Complete coverage is not satisfaction of the framework or deployment approval.

C-style curated evidence can come from beyond the automatic E-style inventory.
Source and protocol hashes, exact text, offsets and context are checked. This is
not primary-quote-quality promotion or verification of the interpretation.
Second-reader targets include every criterion and curated excerpt, bound to the
dossier hash and initially uncertain/unverified.

The NIST assessment credits transparency, representative testing, monitoring,
shutdown/override, decommissioning and iterative review. Full deployment-level
satisfaction remains unestablished without equivalent enforceable coupling,
confidence calibration where applicable, concrete consistency, protection around
irreversible effects and effective self-application. This does not imply that NIST
requires organisations to omit those protections or that an institution has
breached law.

Each source directory retains the completed review, generated assessment,
research dossier and an unfilled second-reader template. No independent reviewer
opinion or operational evidence was fabricated.

sandbox provided Linux/Python 3.13.18. That first sandbox was shut down during an
attempt to build the older PDF extractor; its interrupted full run is not counted
as a pass. Unpublished work was recreated, and a GitHub checkpoint was saved
before fresh validation. No unverified feature was merged.

Poppler 25.03.0 produced different DTA extraction bytes and correctly failed the
reproduction gate. Sources were not repinned. In the replacement sandbox,
official Ubuntu Poppler 24.02.0 packages were extracted to a private runtime
directory, preserving the system. With the recorded extractor version, the full
regulatory re-extraction gate passed: both raw extracts reproduce byte for byte,
45 page-bounded quotations, eight original-Act passages and 16 authored records.
The text assessment route uses only standard-library Python and does not need
Poppler. Runtime dependencies, command versions and final logs are recorded with
the executed verification results.

No paid model API, user's PC or GitHub Actions is required. Python 3.10 and
Windows were not executed in this pass. Source matching cannot prove reasoning
validity, legal force or real control operation. Independent blind comparison,
unfamiliar holdout cases, non-specialist usability and operational studies remain
outstanding.
