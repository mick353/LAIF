## How to read the repository

Product guides describe user workflows. Governance references describe method,
software safeguards and contributor procedures. Dated verification and review
records describe what was observed at that revision, not today's release.
Generated assessments and retained source texts are evidence, not setup guides.
Do not rewrite them merely to make historical wording match the current Site.

The Site's user-guide links follow GitHub `main` so instructions can improve
without upgrading the assessment engine. Source quotations, method identity
and historical reports retain their recorded revisions. A working link does
not establish legal currency, source authority or assessment validity.
